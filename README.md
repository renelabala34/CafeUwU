# I'MAS - Tienda de Comida Casera

Tienda online de comida casera cubana con entrega en Alamar zona 12.

## 🍽️ Productos

### Ofertas sin freír
- Croquetas (embutido, pollo, atún)
- Croquetas rellenas (salchicha, queso, atún)
- Medallones (queso, jamón, jamón y queso)
- Bolitas (queso, jamón)
- Yuca rellena (picadillo, salchicha)

### Especial I'MAS — Preparados
- Tamales (picadillo, pollo, lomo ahumado)
- Banana'MAS (picadillo, picadillo con queso)
- Salchirollos

## 💻 Desarrollo


### Seguridad

- Las contraseñas se almacenan con hash SHA-256 + salt
- El sistema valida fortaleza de contraseña (mínimo 8 caracteres, mayúsculas, minúsculas, números y caracteres especiales)
- Puedes cambiar tu contraseña en cualquier momento desde el panel de administración
